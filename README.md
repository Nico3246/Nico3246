## Selected projects

### [Convivio](https://github.com/Nico3246/Convivio)

Android application for managing shared living through a structured system of users, roles, permissions, and business rules.

The project covers rules, incidents and complaints, recurring tasks, weekly calendars, inventories, shared expenses, reports, authentication, private storage, notifications, audit history, and administrative workflows.

It is currently being tested on real Android devices and includes automated tests, type checking, database validations, and production-oriented build configuration.

**Stack:** React Native · Expo · TypeScript · Supabase · PostgreSQL · Google OAuth · FCM · Vitest

---

### [Zenith](https://github.com/Nico3246/Zenith)

Training management platform for creating routines, recording workout sessions, analysing progress, and providing reviewable AI-assisted recommendations.

The project combines a Python backend, PostgreSQL persistence, authentication, migrations, automated tests, a React Native frontend, deployment configuration, and CI workflows.

**Stack:** Python · FastAPI · SQLAlchemy · Alembic · PostgreSQL · pytest · React Native · Expo · TypeScript · Docker

---

### [Facial Recognition](https://github.com/Nico3246/reconocimiento_facial)

Real-time facial recognition system built in Python.

It detects faces using an SSD model, generates 128-dimensional facial embeddings with OpenFace, trains an SVM classifier, and identifies people from webcam input.

**Stack:** Python · OpenCV · OpenFace · Caffe · scikit-learn · NumPy

---

### [Chess with Alpha-Beta AI](https://github.com/Nico3246/Ajedrez)

Chess implementation with custom board logic, move validation, heuristic position evaluation, and an AI opponent based on Minimax with alpha-beta pruning.

The repository also includes unit and integration tests for the game logic and search implementation.

**Stack:** Python · Minimax · Alpha-Beta Pruning · pytest
